# clippyXam 0.9.0 — Windows 10/11 x64 Portable

Скачай **clippyXam-0.9.0-win-x64-portable.exe** из Assets в GitHub Releases. Это готовое приложение, без установки, Node.js и npm. Автоматический Source code ZIP — не приложение.

## Обновление и запуск

1. Закрой старую версию, в том числе через трей → Выход.
2. Положи новый EXE в ту же папку с правом записи. Сохрани `clippyXam-data`: там зашифрованный ключ, настройки и голос. Старые релизы не удалены.
3. Запусти EXE без администратора. При отсутствии ключа появятся инструкции и ссылка `openrouter.ai/keys`.
4. Ключ OpenRouter сохраняется через Windows DPAPI. После переноса на другую учётную запись/компьютер может потребоваться повторный ввод, но создавать новый ключ необязательно.

Сборка предварительная, без цифровой подписи. Возможны предупреждения SmartScreen; сверяй источник и SHA-256, не отключай защиту вслепую.

## Новая Скрепка с инерцией

По умолчанию используется новая отрисовка Скрепки. Потяни настоящее окно за заголовок:

- плавно — слабая реакция;
- немного быстрее — заметно наклоняется по инерции, без удара;
- резкий рывок — впечатывается в противоположный край и отскакивает;
- резкая остановка — качает вперёд, затем успокаивается.

Слабая тряска при печати сохранена. В виджете та же механика. Системное reduced motion выключает реакции. Настройки → Поведение содержит просмотр трёх уровней и флажок «Новая Скрепка: инерция и удары»; отключение возвращает исходный режим.

Это первый перенос согласованной механики. Новые рисунки пока только для Скрепки; Rover/Merlin остаются в исходном режиме. Промежуточные движения строятся локальной деформацией новых рисунков, а не поворотом картинки. Отдельные вертикальные ударные позы и расширенные новые анимации ещё в работе. Нужна проверка физического перетаскивания и DPI на твоём компьютере.

## Что изменилось

- Стандартный **openrouter/free** теперь реально первый; Liquid больше не выбирается. При обновлении с 0.7 маршрут переключается на router, обычная скорость голоса — на 1.25. Остальные настройки и ключ сохраняются.
- Убраны ограничения в 250 символов/12 слов. Длинные ответы прокручиваются внутри облачка, включая время отсутствия маскота. Конечный лимит: 2048 токенов модели / 12000 символов отображения.
- Автоматическое закапывание с одинаковой фразой убрано. Вместо SVG-накладок — оригинальные кадры Clippy/Merlin/Rover, разные самостоятельные действия, подрагивание при вводе и направленные реакции на движение окна. Reduced motion отключает движение.
- **Настройки сохраняются сами**, без «Применить». Статус сверху. X/Esc/«Готово» дожидаются записи. При ошибке сохранения диалог остаётся открытым. Флажок автозапуска меняет настройку Windows сразу, только по твоему действию.
- Голос держит модель загруженной, начинает с короткого фрагмента, готовит следующий во время проигрывания. Скорость регулируется в пределах 0.7–1.8. Текст появляется с первым звуком, но не задерживается больше четырёх секунд, если голос не готов.

## Соединение

Настройки → Подключение → Бесплатная модель. Ручной выбор первый; при включённом резерве дальше только бесплатные модели. До четырёх разных ID, до 15 секунд на попытку. Платного fallback нет. Бесплатный API имеет очереди/лимиты; скорость не гарантируется. Неудачное сообщение остаётся в поле, новый черновик не затирается.

Техническая ошибка не попадает в реплику и озвучку. Точка на шестерёнке → Настройки → Подключение → **Диагностика подключения и голоса**:

- `[DNS]` — проверить DNS и доступность OpenRouter.
- `[TLS]` — проверить дату Windows, HTTPS-фильтрацию/прокси; не отключать проверку сертификатов.
- `[PROXY]`, `[CONNECTION]`, `[OFFLINE]` — проверить сеть/прокси/VPN.
- `[INVALID_KEY]` — только сам ключ, без пробелов/переносов/нелатинских символов.

401 возвращает окно подключения. 429 — лимит бесплатных запросов; смена модели не обходит общий лимит аккаунта. В отзыве достаточно кода/версии, **ключ не присылай**.

## Голос, окно и данные

Piper/Denis автоматически скачивает проверенный русский голос (~63 МБ) при первом запуске. Далее работает локально, без голосов Windows и без платного API. Один тембр для всех персонажей. При ошибке загрузки — Настройки → Голос → Повторить загрузку. Первое скачивание требует доступа к Hugging Face. Реальная скорость зависит от компьютера.

Системный TTS — альтернатива. OpenAI TTS отдельно помечен как платный и требует отдельного ключа; автоматически не включается. Микрофон использует совместимый Windows System.Speech ru-RU, не Piper. Если распознавателя нет, используй поле ввода/Win+H.

Характер по умолчанию грубый комедийный. «Без подколов» или мягкий режим в настройках отключают хамство. Маскот не читает экран, файлы и открытые приложения.

Виджет и пропуск прозрачных кликов включаются в настройках. Рамка/кнопки/ввод защищены, при сбое пропуск отключается. Возврат — Esc/трей/рамка. Для повторного включения после fail-safe сними и снова поставь флажок.

Автозапуск использует путь текущего portable. Перед переносом/удалением выключи, после переноса включи заново. При обновлении имени EXE выключи и включи флажок из новой версии. Реальный вход в Windows требует проверки на твоём компьютере.

`preferences.json` содержит только несекретные настройки; переписка, черновики и аудио не сохраняются. Ключ — отдельный зашифрованный файл. Удаление только preferences.json при закрытом приложении сбрасывает настройки, но не ключ.

Courtney/Earl, оригинальная анимация среднего пальца, фонемная артикуляция и подпись пока отсутствуют. Наложенные сценки 0.7 удалены после отзыва о качестве. Проверки CI не заменяют прослушивание, реальный микрофон, GPU/DPI, физические клики и мониторы. Права на artwork — в THIRD_PARTY_NOTICES.md.
