# clippyXam 0.6.1 — portable, Windows x64

1. Скачай `clippyXam-0.6.1-win-x64-portable.exe` в отдельную папку с правом записи (например, `Документы\clippyXam`). Запускай обычным пользователем, не администратором.
2. Установка, Node.js/npm, отдельный Electron и локальный dev-сервер **не нужны**. Интернет нужен для OpenRouter, не для загрузки персонажей.
3. В первом окне создай/вставь ключ https://openrouter.ai/keys. Ключ сохраняется зашифрованным через Windows DPAPI для твоей учётной записи и подставляется при следующем запуске. Новый ключ каждый раз создавать не нужно. По умолчанию автовыбор бесплатных моделей, платных моделей/fallback нет. Бесплатные модели имеют очереди/лимиты; скорость не гарантирована.
4. Enter отправляет; шестерёнка открывает настройки персонажа/виджета/голоса/характера. × завершает приложение. Виджет возвращается через кнопку рамки/Esc/трей.

## Что означает portable

Это один самораспаковывающийся exe **без установщика**, автозапуска, ярлыков и регистрации приложения. При старте Electron распаковывается во временную папку Windows; нормальный выход очищает временный payload, после аварии могут остаться временные файлы.

Рядом с exe создаётся `clippyXam-data` для геометрии и служебных данных Chromium. Переписка и ключ OpenAI TTS на диск не сохраняются. Ключ OpenRouter хранится в зашифрованном файле openrouter-key.bin, без открытого текстового fallback. Для сброса/удаления закрой приложение и удали exe и эту папку. Не запускай из read-only папки/архиватора/Program Files. Файл большой, потому что содержит Electron и ресурсы трёх персонажей. Первый запуск может быть медленным из-за распаковки/проверки антивирусом.

**Сборка не подписана сертификатом.** Windows SmartScreen/антивирус может показать предупреждение о неизвестном издателе. Сверь источник и SHA-256; не отключай защиту и не обходи блокировку вслепую. Если Windows блокирует файл — пришли точный текст без секретов.

## Микрофон

Встроенная кнопка использует локальный Windows System.Speech. Нужен совместимый **ru-RU recognizer**, default microphone и разрешение для классических приложений. Русский языковой пакет и работа Win+H не гарантируют наличие System.Speech recognizer. Ошибка теперь показывает причину и запасной путь.

Если совместимого распознавателя нет: нажми поле сообщения, затем **Win+H**, используй штатный голосовой ввод Windows и после проверки текста нажми Enter. Это отдельная функция Windows, которая может требовать интернет/включение онлайн-распознавания. Приложение не устанавливает движки и не включает облачное распознавание без твоего действия.

Наша кнопка вставляет текст, не отправляет его сразу. Повторное нажатие отменяет; сворачивание/скрытие/закрытие останавливают процесс. Реальная работа с твоим микрофоном ещё требует проверки.

## Русский голос — автоматически

Озвучка включена по умолчанию. Движок Piper идёт внутри portable, а голос Denis (63 МБ) скачивается при первом запуске с Hugging Face и проверяется по закреплённым контрольным суммам. Нужен интернет для первой загрузки; дальше озвучка локальная, без установленных голосов Windows и без отправки текста в облако. Файлы хранятся рядом с exe в `clippyXam-data/voices/denis-v1`. При блокировке Hugging Face появится ошибка; повтор — Настройки → Голос → Повторить загрузку. Один русский голос используется для всех трёх персонажей, его скорость настраивается.

**Модель выбирается в Настройки → Подключение → Бесплатная модель.** Раскрываемый список обновляется из каталога OpenRouter без отправки ключа. Компактные модели стоят первыми (ориентир по размеру, не гарантированная скорость), остальные бесплатные — резерв. Если каталог недоступен, остаётся встроенный/последний список. По умолчанию автовыбор; при ручном выборе сначала пробуется выбранная модель.

Если модель не отвечает, вернула HTTP 400/404/408/429/5xx, пустой или неправильно-языковой ответ, приложение пробует другую. До 4 разных ID, до 9 секунд на попытку, последний резерв — `openrouter/free`. На 401/402/403 перебор прекращается. Флажок автопереключения можно снять. При 400 следующий запрос упрощается: меньше контекста, без отдельной system-role; параметры рассуждения не навязываются. Нулевые ограничения цены сохраняются, платных моделей нет. Отмена останавливает всю цепочку.

Каждая попытка расходует бесплатный лимит, общий лимит аккаунта обойти сменой модели нельзя. Сообщение может попасть нескольким провайдерам, у каждого свои правила хранения/обучения — не отправляй секреты. Скорость/доступность живых моделей не гарантированы. При полном отказе текст остаётся в поле, ошибка показывает коды и названия проверенных моделей без сырого ответа провайдера.

По умолчанию включён жёсткий комедийный характер с матом; мягкий режим — в настройках или «без подколов». Выглядывание — отдельная анимация, а не реальное наблюдение: приложение не читает экран, открытые программы или файлы.

## Остальные варианты озвучки и ограничения

Озвучка ответов отдельно: настройки → Голос → Озвучивать ответы. Системный TTS остаётся альтернативой и требует голоса ОС; необязательный OpenAI TTS платный, включается явно с отдельным ключом.

Доступны Clippy, Rover, Merlin. Courtney/Earl, оригинальный грубый жест, фонемная артикуляция и автозапуск не готовы. Жест — новая SVG-накладка. Пропуск кликов не включён; прозрачные участки виджета могут перехватывать мышь. Microsoft artwork имеет отдельные вопросы прав; см. THIRD_PARTY_NOTICES.md.

При ошибке: версия Windows/DPI, что нажал, ожидание/результат и снимок без ключей. Проверь также виджет, отмену ответа, сворачивание/выход, системный голос. Автоматический smoke-test не заменяет проверку микрофона, GPU/прозрачности и нескольких мониторов на твоей машине.

## Сохранено из 0.5.0

- Ответы с иероглифами не показываются; в 0.6 вместо повтора на той же модели включается ограниченный перебор других бесплатных моделей.
- При ошибке отправки сообщение остаётся в поле. Если уже пишешь другое — новый текст не затирается. Неуспешная попытка удаляется из контекста, чтобы повтор не дублировал сообщение.
- Восемь мемных сценок доступны в Настройки → Поведение → Просмотр мемной сценки. Автоматически они выбираются по фразам и раздражению, редкие случайные — с паузой. Мягкий режим/запрет грубых жестов/тихие часы отключают автоматические сценки.
- На обвинение в «незаконной» реплике с вероятностью 90% включается мемный арест, только если предыдущая реплика маскота содержит грубость или шуточную угрозу Windows. Это игровая эвристика по словам, **не юридическая проверка**. Решётка/пиксели/бита/огонь ничего не делают с системой.
- Ключ OpenRouter можно удалить: Настройки → Подключение → Удалить сохранённый ключ при применении → Применить. После переноса на другой компьютер/учётную запись Windows расшифровать его может быть невозможно; тогда введи прежний ключ заново. Если безопасное шифрование недоступно, открытого сохранения не будет.

## Если снова ошибка связи (0.6.1)

Чат и каталог теперь подключаются через основной процесс Electron, без браузерного запроса из clippyxam://. При общей сетевой ошибке модели больше не перебираются вслепую. Показывается код:

- `[DNS]` — адрес OpenRouter не найден: проверить DNS/доступность сети.
- `[TLS]` — сертификат не прошёл проверку: проверить дату Windows и HTTPS-фильтрацию/прокси; защиту не отключать.
- `[PROXY]` — не проходит соединение через прокси/VPN.
- `[CONNECTION]` / `[OFFLINE]` — соединение сброшено/отклонено либо нет интернета.
- `[INVALID_KEY]` — вставить только ключ, без пробелов/переносов/нелатинских символов.

Для отзыва достаточно кода и версии; ключ не присылать. Точный исходный сбой по прежнему общему сообщению не установлен. Старый exe закрыть, новый запускать из той же папки, сохранив `clippyXam-data`. Повторно создавать ключ не нужно.
