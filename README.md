# clippyXam 0.9.0 — нейрохам, NT Portable

Минимальная серая NT-рамка, оригинальные Clippy/Rover/Merlin, реплика, поле Enter, микрофон и настройки. Грубый комедийный персонаж с мягким режимом, не системный администратор: не наблюдает экран и не выполняет угрозы «снести Windows».

## Запуск

[GitHub Releases](https://github.com/znik78521-source/clippyXam/releases): `clippyXam-0.9.0-win-x64-portable.exe`, Windows 10/11 x64. Без установщика, Node.js и npm. Не скачивай Source code ZIP вместо приложения. Инструкция: [PORTABLE-RU.md](PORTABLE-RU.md).

EXE распаковывается во временную папку; данные — рядом в `clippyXam-data`. Нужна папка с правом записи, не администратор. Предварительная версия без цифровой подписи: сверяй источник/SHA-256, не отключай защиту Windows вслепую.

## Новое в 0.9 — Скрепка с инерцией

- Новая отрисовка Скрепки включена по умолчанию: спокойная поза, любопытство, отдельные новые рисунки ударов слева/справа. В этом режиме готовые Agent-кадры не загружаются. Рисунки — генерации по референсу; промежуточные фазы используют локальную деформацию, не вращение всей картинки и не независимую перерисовку каждого кадра.
- Три уровня: слабое покачивание при плавном движении, заметный упругий наклон при умеренном разгоне, удар при очень резком рывке. Сила зависит от изменения скорости окна. При торможении — качание вперёд, при постоянной скорости дополнительной силы нет. После удара — короткая пауза и затухающий отскок. Тряска при наборе не усиливалась.
- Ограниченные относительные скорости DIP/s из main, без экранных координат. Сброс при resize/maximize/hide/больших позиционных скачках, защитная остановка при потере завершающего события. Основное окно и виджет; reduced motion отключает движения.
- Во время инерции hit-map консервативный, после остановки снова альфа-маска. Кнопки и ввод остаются защищены.
- **Пока только Скрепка.** Rover/Merlin всё ещё используют исходные ресурсы. Новые вертикальные ударные позы, расширенные idle и мемные сцены не закончены. Настройки → Поведение → «Новая Скрепка: инерция и удары» позволяет явно вернуть предыдущий режим. Предварительный вид рисунков не объявляется идеально совпадающим с оригиналом.

## Исправления 0.8

- **Оригинальные анимации:** разнообразные самостоятельные действия, короткое подрагивание при каждом вводе, отдельные направленные последовательности при движении окна и возврат позы после остановки. Направленные позы собираются из оригинальных кадров, не CSS-вращения. Проверяются не только имена состояний, но и изменения пикселей canvas. Reduced motion выключает движения.
- **Удалены SVG-рука и восемь наложенных сценок.** Принудительное закапывание при раздражении и замена ответа одной заготовленной фразой убраны. Автоматический уход ограничен паузой в две минуты. Длинная реплика остаётся читаемой во время отсутствия и после возвращения.
- **Ответы больше не ограничены инструкцией в 250 символов/12 слов.** Запрос допускает 2048 токенов, отображение — до 12000 символов, длинный текст прокручивается. Сохраняются абзацы. Это всё ещё ограниченный бюджет, не обещание бесконечного ответа.
- **Стандартный `openrouter/free` действительно первый.** Liquid исключён. Настройки 0.7 мигрируют на router и скорость 1.25; прочие предпочтения сохраняются. Последующий ручной выбор сохраняется.
- **Голос:** модель Piper не перезагружается на каждую реплику. Короткий первый фрагмент и подготовка следующего во время воспроизведения уменьшают задержку. Скорость 1.25 по умолчанию, диапазон 0.7–1.8. Текст показывается с началом звука; если голос задержался, текст не удерживается больше четырёх секунд. Смена скорости/отмена перезапускают worker при необходимости. Аудио остаётся в RAM.
- **Настройки сохраняются автоматически** после короткой паузы, запись последовательная, X/Esc/«Готово» дожидаются сохранения. Ошибка записи не закрывает диалог. Отдельного «Применить» нет.
- **Технические ошибки не озвучиваются и не становятся репликами.** Точка на шестерёнке ведёт в диагностику настроек. Неудачное сообщение остаётся в поле; новые правки не затираются.

## Чат, голос и данные

Чат — OpenRouter, только `openrouter/free` и нулевые по цене `:free`. Ручной выбор пробуется первым, затем router и остальные бесплатные кандидаты. До четырёх разных ID, до 15 секунд на попытку, общий watchdog 65 секунд. Fallback можно выключить. DNS/TLS/proxy/общий сетевой сбой и 401/402/403 прекращают перебор. После HTTP 400 применяется совместимый формат с меньшим контекстом. Повторы расходуют квоту; общий лимит аккаунта сменой модели не обойти. Скорость бесплатного API не гарантируется.

В portable чат/каталог идут через owner-only IPC → Electron `net.fetch`, только два фиксированных HTTPS URL; zero-price повторно проверяется в main. Без отключения TLS/CORS/sandbox. История в RAM, контекст ограничен 20 сообщениями/32000 символами. Каталог запрашивается без ключа. Сообщение может попасть нескольким провайдерам; не отправляй секреты.

Ключ OpenRouter — отдельный зашифрованный DPAPI vault. При отсутствии безопасного шифрования plaintext fallback нет. В браузере ключ только в RAM. Предпочтения — allowlist в `preferences.json`, без ключей, истории, черновиков и аудио. Платный TTS не восстанавливается автоматически; виджет включается вручную после запуска.

Русский **Piper/Denis** включён в portable по умолчанию: движок в EXE, голос автоматически скачивается один раз (63 МБ, закреплённая ревизия и проверяемые хеши) в `clippyXam-data/voices/denis-v1`. Далее текст озвучивается локально, без голосов Windows/API. Один тембр для трёх персонажей. Системный TTS и явно подключаемый **платный OpenAI TTS** — альтернативы; ключ OpenAI только в RAM. Микрофон — отдельный экспериментальный Windows System.Speech ru-RU, не Piper; запасной ввод — Win+H.

## Окно и ограничения

Пассивный виджет не получает ключи/историю и не запускает второй чат/TTS. Возврат через рамку/Esc/трей. Пропуск кликов — по явному согласию, альфа-маска текущего кадра, защищённые кнопки/ввод и fail-safe; сложные переходы используют консервативную область. Координаты мыши/окна не отправляются в чат; renderer получает только ограниченную относительную скорость и направление, без координат.

Автозапуск Windows по умолчанию выключен, меняется только явным флажком; используется стабильный путь portable EXE, не временная распаковка. Перед переносом/удалением выключить, после переноса включить заново.

Courtney/Earl, оригинальные грубые кадры, фонемная артикуляция и подпись пока отсутствуют. Старые SVG-сценки не выдаются за оригинальные ресурсы. [ROADMAP](docs/ROADMAP.md), [THIRD_PARTY_NOTICES](THIRD_PARTY_NOTICES.md).

## Разработка и проверки

Node.js 22.12+:

```sh
npm ci
npm run verify
npm run dev                   # browser preview
npm run desktop:dev           # Electron + Vite
npx playwright install chromium
npm run test:e2e
npm run portable:win          # Windows: Piper + portable
```

CI проверяет реальную последовательную работу Piper, смену скорости/отмену; packaged/portable; живой каталог OpenRouter 200 и invalid-key POST 401 через native IPC. **Это не генерация с пользовательским ключом.** Прослушивание, микрофон, физические DPI/мониторы и вход в Windows требуют ручной проверки. [TEST-REPORT](docs/TEST-REPORT.md), [WINDOWS-QA](docs/WINDOWS-QA.md). Бинарники только в Releases; старые релизы/данные не удаляются.
