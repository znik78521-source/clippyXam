# clippyXam

**Старый знакомый. Новый характер.** Неофициальный фан-прототип помощника с оригинальными Clippy/Rover/Merlin, сарказмом и OpenRouter. Версия **0.3.0 — NT/minimal Portable**: серая классическая рамка, персонаж, облачко, ввод, микрофон и настройки. Это стилизация, не поддержка самой Windows NT.

## Portable для Windows — основной способ проверки

В [GitHub Releases](https://github.com/znik78521-source/clippyXam/releases) выбирай **`clippyXam-0.3.0-win-x64-portable.exe`** в Assets, не автоматический Source code ZIP. Сборка публикуется только после успешных Windows-проверок. Для запуска **не нужны Node.js, npm, установщик или локальный сервер**. Windows 10/11 x64; инструкция — [PORTABLE-RU.md](PORTABLE-RU.md).

Приложение самораспаковывается во временную папку, а `clippyXam-data` создаёт рядом с exe. Каталог должен быть доступен для записи, администратор не нужен. Ключи/чат остаются только в RAM. Бинарник **без цифровой подписи**, поэтому возможны предупреждения SmartScreen; сверяй SHA-256 и источник, не отключай защиту вслепую.

Сборка на Windows: `npm ci`, `npm run verify`, `npm run portable:win`. Выход — `release/*-portable.exe`, не установщик. Workflow запускает также тесты packaged-окна и самого portable exe перед публикацией предварительного релиза. Это не проверка живого микрофона, всех GPU/DPI или ответов реального API.

## Проверить исходники на Windows

Распакуй весь архив и запусти **START-WINDOWS.cmd**. Нужны Windows 10/11, **Node.js 22.12+** и интернет для установки зависимостей. Подробности: [START-HERE-RU.md](START-HERE-RU.md). Архив не содержит готового приложения; Node нужен для этого теста исходников, но не потребуется отдельно пользователям будущего упакованного Electron-приложения.

```sh
npm ci
npm run desktop:dev
```

Launcher поднимает локальный Vite на 127.0.0.1 (с порта 5174, выбирает свободный) и Electron. При выходе сервер останавливается. `npm ci` скачивает готовый Electron runtime — это зависимость, не сборка нашего `.exe`. Пользователь разрешил portable-упаковку; тест исходников остаётся дополнительным вариантом для разработки.

Для браузерного предпросмотра: `npm run dev`. Сервер слушает 0.0.0.0, разрешён preview-хост `*.e2b.app`. Виджет в браузере — только отображение внутри страницы, не поверх рабочего стола.

## Подключение и стоимость

- При каждом запуске без ключа открывается окно подключения со ссылкой https://openrouter.ai/keys и инструкцией. Ключ проверяется первым запросом. После 401 снова требуется ключ. Демо-режима нет.
- По умолчанию **openrouter/free**. Допускаются только этот маршрут и конкретные ID вида `vendor/model:free`. Запрос задаёт `provider.sort: latency` и нулевые ограничения цены входных/выходных токенов. Платного fallback нет.
- Маршрут выбирает доступную бесплатную модель; предпочтение низкой задержки провайдера **не гарантирует самую быструю модель**. Возможны очереди, ограничения и 429. При отказе приложение показывает ошибку, не переключается на платный маршрут.
- В OpenRouter передаются системная инструкция и до 20 последних сообщений выбранного персонажа. Ответ ограничен 350 токенами, ожидание — 45 секундами. Отмена игнорирует поздние результаты, но не обещает остановку обработки у сервиса.
- Ключи, разговоры и настройки голоса живут только в RAM. На диск сохраняются геометрия/режим окна/always-on-top, а не переписка или ключи. Не присылай секреты в отчётах.

## Управление

**Enter** отправляет текст. Микрофон вставляет распознанное в поле: отправка — отдельно. Шестерёнка открывает персонажа, дерзость, подключение, голос и поведение. Во время запроса появляется отмена; во время озвучки — остановка голоса.

Начальное native-окно 360×460, минимальное 320×400. Перетаскивание за заголовок; сворачивание и разворачивание — кнопками рамки, × завершает приложение. Always-on-top, мини-режим и скрытие доступны через меню трея. Геометрия сохраняется; старый профиль может восстановить прежний размер.

**Настройки → Виджет на рабочем столе** открывает отдельное прозрачное окно со стилизованной полоской управления. Основное окно скрывается только после подтверждения готовности поверхности. Оно остаётся единственным владельцем чата, ключей, таймеров и озвучки; поверхность получает только разрешённый снимок отображения и передаёт разрешённые действия. Настройки из виджета временно открывают владельца; отмена возвращает виджет. Возврат: кнопка рамки, Esc, трей или повторный запуск. × виджета завершает приложение; системное Alt+F4 возвращает владельца. Сбой поверхности возвращает владельца. Виджет не восстанавливается автоматически при следующем запуске.

**Пропуск кликов сейчас не включён в минимальный UI.** Старые защитные контроллеры сохранены и тестируются, но штатно выключены. Это не готовая пиксельная маска; прозрачные участки окна могут перехватывать клики.

## Голосовой ввод и озвучка — разные функции

- Native-ввод: фиксированная локальная команда Windows PowerShell / System.Speech, default microphone, **совместимый установленный ru-RU SpeechRecognitionEngine**. Обычный русский языковой пакет или работа Win+H не гарантируют его наличие. Без него показывается ошибка, текстовый ввод остаётся доступным. Возможность экспериментальная, реальный Windows-микрофон здесь не проверен.
- Только явное нажатие микрофона запускает запись/распознавание; повторное отменяет. Распознавание ограничено 15 секундами ожидания, процесс — watchdog 22 секундами. Аудиофайлы приложение не записывает; командная строка не содержит пользовательский текст. Закрытие renderer/приложения отменяет процесс.
- В браузере используется SpeechRecognition при наличии; браузер может отправлять аудио поставщику. В Electron macOS/Linux native-ввод пока не поддержан. Ограничение browser-сеанса — 20 секунд.
- Ответы: **Настройки → Голос → Озвучивать ответы**. По умолчанию звук выключен, выбран системный TTS. Нужен доступный голос ОС. Есть очередь/отмена и реальные word-boundary подсветки, если драйвер их сообщает.
- Необязательный **OpenAI TTS — платный**, включается явно с отдельным ключом; бесплатный чат не делает его бесплатным. Автоматического перехода на него нет. До 30 сетевых попыток за сеанс, RAM-кэш до 20 аудио/20 МиБ, без сохранения аудио на диск.

## Персонажи и ограничения

Clippy, Rover, Merlin — исходные ресурсы `clippyjs@0.1.0`: 145 анимаций / 3284 кадра, исходные ветви/слои/длительности. Нужные файлы извлекаются из npm при запуске; спрайт-листы не вложены отдельно в ZIP. Microsoft artwork имеет отдельные вопросы прав: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Есть разговор, обида, накопительное раздражение, временный уход, выглядывание и возврат, мягкий режим, тихие часы и opt-in память отдельных разговоров на время сеанса. Приветствия/подтверждения локальных настроек — не ответы нейросети. Грубый жест — **новая SVG-накладка**, не оригинальные кадры. Courtney/Earl отключены: нет проверенных ресурсов. Фонемная артикуляция и автозапуск не реализованы.

## Проверки без сборки

```sh
npm run verify              # TypeScript, логика, desktop/mock, launcher, audit ресурсов
npx playwright install chromium
npm run test:e2e            # браузерные сценарии с подставными API/голосами
```

`CHECK-WINDOWS.cmd` выполняет `verify`, без E2E и сборки. В sandbox зависимости Electron ставились с `ELECTRON_SKIP_BINARY_DOWNLOAD=1`; на своём Windows так делать не нужно. Для своего Chromium можно задать `CHROMIUM_PATH`.

Результаты: [TEST-REPORT.md](docs/TEST-REPORT.md). Реальная Windows-прозрачность, трей, DPI, системный голос/микрофон и живой OpenRouter **не подтверждены** тестами с mock. Следующий шаг: [WINDOWS-QA.md](docs/WINDOWS-QA.md), затем исправления по результатам тестирования portable-версии.

## Безопасность оболочки

Electron: sandbox/contextIsolation включены, Node в renderer выключен. IPC проверяет WebContents, главный frame, origin и аргументы; произвольного shell/file/IPC доступа нет. Микрофонный мост запускает только фиксированный скрипт с bounded output и owner-scoped отменой. Внешние ссылки ограничены, webview и встроенная навигация заблокированы. CSP ограничивает API OpenRouter/OpenAI. В dev разрешён только loopback Vite URL. В packaged-версии используется закрытая схема `clippyxam://bundle/`, путь ограничен папкой ресурсов, remote renderer URL из окружения игнорируется. Production CSP не разрешает eval и inline-скрипты.
