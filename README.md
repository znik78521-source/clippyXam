# clippyXam

**Старый знакомый. Новый характер.**

Неофициальный фан-прототип виртуального помощника в стиле Windows XP: оригинальные спрайты, диалог через OpenRouter, сарказм, обиды и демонстративный уход за кадр.

## Архив для Windows-теста

Распакуй весь архив и начни с [START-HERE-RU.md](START-HERE-RU.md). `START-WINDOWS.cmd` проверяет Node, при первом запуске устанавливает locked-зависимости и открывает исходники Electron. `CHECK-WINDOWS.cmd` запускает проверки без сборки. Нужны Node.js 22.12+ и интернет для первой установки; это не portable `.exe`.

## Запуск

Нужен Node.js **22.12+**. Для desktop — современная Windows (10/11), macOS или Linux с графическим сеансом. Это **стилизация под XP**, не поддержка самой Windows XP.

```bash
npm ci
npm run dev
```

Открыть адрес Vite (обычно `http://localhost:5173`). Сервер слушает `0.0.0.0`; хосты предпросмотра `*.e2b.app` разрешены. В браузерном коде нет обращений к localhost: чат-запросы идут напрямую в OpenRouter, а опциональная облачная озвучка — в OpenAI.

```bash
npm run verify      # все source-проверки без сборки (включая dev-launcher)
npm run check       # проверка TypeScript без генерации файлов
npm test            # тесты логики чата и поведения
npm run test:desktop # геометрия окна, команды, preload и проверки безопасности
npm run audit:agents # проверка PNG/кадров и SHA-256 исходных ресурсов
npx playwright install chromium
npm run test:e2e   # браузерные сценарии, Vite запускается автоматически
```

В среде с предустановленным Chromium можно указать `CHROMIUM_PATH=/path/to/chromium npm run test:e2e`. Браузерные тесты перехватывают OpenRouter/OpenAI-запросы и не тратят деньги. Для запуска в ограниченной среде могут понадобиться системные библиотеки Chromium.

## Настоящее XP-окно — dev-режим

```bash
npm ci
npm run desktop:dev
```

Это запуск **исходников Electron + Vite**, не компиляция и не упаковка. Скрипт подготавливает спрайты, поднимает отдельный локальный Vite на `127.0.0.1` (начиная с порта 5174) и открывает Electron. При выходе из Electron Vite останавливается. HMR работает для React/CSS; изменения `electron/*.cjs` требуют перезапуска команды. Если порт 5174 занят, выбирается следующий: второй запуск всё равно доходит до single-instance проверки Electron, после чего его временный сервер закрывается.

- Начальное окно **420×650**, XP-рамка без системного заголовка и без нарисованного рабочего стола. Размер и позиция запоминаются отдельно для полного и компактного режима.
- Синяя полоса — нативная область перетаскивания; границы окна позволяют менять размер.
- **Булавка** переключает always-on-top (по умолчанию включён).
- **«\_»** сворачивает в настоящую панель задач. **«□»** открывает полный режим и разворачивает окно. **«×» завершает приложение**, а не прячет его.
- **Вид → Скрыть в системный трей** скрывает без выхода. В трее: вернуть окно, компактный режим, always-on-top, выход. Если создание трея не удалось, команда недоступна. В некоторых Linux-оболочках нужен модуль AppIndicator; не скрывай окно в трей, если значок не отображается. Повторный запуск возвращает уже работающее окно.
- Компактный режим содержит чат, последний ответ, выбор персонажа и дерзости. Переход в полное окно не сбрасывает разговор.
- При отключении монитора координаты ограничиваются доступной рабочей областью.

В `app.getPath('userData')/window-state.json` сохраняются **только** размеры, координаты, режим окна и always-on-top. Никаких API-ключей и переписок. Desktop-сессия Chromium непостоянная.

На этапе установки Electron скачивает готовый runtime для ОС — это зависимость, не сборка нашего приложения. В sandbox runtime намеренно не скачивался (`ELECTRON_SKIP_BINARY_DOWNLOAD=1`), так как графического сеанса здесь нет. На своём компьютере используй обычный `npm ci` без этой переменной. Если установка runtime была пропущена: `npm rebuild electron`, затем `npm run desktop:dev`.

**Проверено здесь:** типы без компиляции, чистая логика контроллера окна и preload, браузерные сценарии с подставным desktop-мостом. **Не проверено:** реальное нативное окно/трей/голоса на Windows. Electron в этой среде не запускался. Установщик, `.exe` приложения, подпись и production-упаковка **не создавались и не настроены**. Команда `npm run build` из первого этапа относится только к веб-части; на текущем этапе её не запускали.

### Маскот на рабочем столе

**Вид → Маскот на рабочем столе** открывает отдельную прозрачную поверхность 360×460 (при нехватке места ограниченную рабочей областью монитора): персонаж, облачко, поле ввода и маленькая панель управления. Перетаскивание — за имя/точки в верхней полоске. Закрепление наследуется от XP-окна.

Исходное XP-окно не пересоздаётся: оно скрывается только после нативной готовности и подтверждения от React, что получен и отображён снимок состояния. Оно остаётся единственным владельцем диалога, ключей, таймеров и озвучки. У прозрачного окна отдельный preload: только отображаемая реплика/состояния, отправка/отмена ответа, выбор одного из трёх доступных персонажей, переключение/остановка звука, вызов маскота обратно и возврат к XP. Настройки, ключи, история и аудиокэш не передаются этому renderer.

Над полем ввода есть **выбор персонажа** и **«Стоп голос» / «Стоп TTS»**. Смена персонажа отменяет незавершённый ответ и озвучку; отдельная история восстанавливается только при включённой памяти сессии. Повторный выбор текущего персонажа не сбрасывает диалог. Пока смена не подтверждена владельцем, новая отправка блокируется; если подтверждения нет 4 секунды, появляется уведомление. Courtney/Earl указаны как недоступные, без подмены ресурсов.

При ожидании ответа доступна кнопка **«Стоп»**, также в полном и компактном XP-окне. Она отменяет локальное ожидание/запрос и игнорирует поздний результат. Уже отправленное сообщение остаётся в истории и может попасть в последующий контекст модели. **Отмена не гарантирует прекращение обработки или возврат оплаты у провайдера.** Остановка голоса очищает текущую озвучку и очередь, но не выключает динамик для следующих реплик.

**XP / Esc**, клик по трею, пункт «Вернуть XP-окно» или повторный запуск возвращают основное окно. Alt+F4 в прозрачном окне **возвращает XP**, а не завершает приложение. Ошибка/таймаут загрузки (15 секунд) или падение прозрачного renderer также возвращают владельца. При выходе из приложения оба окна закрываются. Запоминается отдельная позиция; сам прозрачный режим после перезапуска не включается.

В браузере эта команда показывает **подписанный предпросмотр внутри страницы**, а не окно поверх других приложений. Панель задач предпросмотра также возвращает XP-комнату.

**Пропуск кликов:** кнопка со стрелкой мыши в верхней полоске включает экспериментальный режим. По умолчанию он выключен и не сохраняется. В исходниках native-режим доступен только для Windows/macOS; Linux пока остаётся с обычным захватом кликов. В браузере это лишь CSS-предпросмотр внутри страницы.

Это грубая проверка прямоугольных областей, **не пиксельная маска**. Панели, облачко, область персонажа и кнопка возврата сохраняют захват; вокруг них оставлены защитные поля. Даже некоторые прозрачные пиксели внутри этих областей остаются кликабельными. Основной процесс проверяет курсор каждые 50 мс, а renderer сообщает ограниченный набор прямоугольников каждые 250 мс. На быстрых движениях/кликах возможна задержка переключения — обязательно проверить на целевой ОС, особенно при разном DPI мониторов.

Если карта областей не обновляется более 1,25 секунды, режим автоматически **выключается**, а обычный захват кликов возвращается. Так же обрабатываются ошибочная карта, перезагрузка/зависание интерфейса, скрытие и сворачивание. Долгое зажатие указателя или фокус на списке персонажей (10 секунд) тоже отключает режим; позднее обновление не включает его заново. Перетаскивание и фокус на выпадающем списке временно защищают захват, смена геометрии сбрасывает старую карту. При сбое остаётся возврат через трей или повторный запуск.

Прозрачность, click-through, фокус, перенос между мониторами и поведение GPU **ещё не проверены в настоящей Windows/macOS**. Если экспериментальный режим мешает — отключи кнопку или верни XP-окно. Чек-лист — [WINDOWS-QA.md](docs/WINDOWS-QA.md).

### Безопасность desktop

`contextIsolation` и `sandbox` включены, Node в renderer выключен. Preload предоставляет только перечисленные команды окна, без произвольного IPC или доступа к файлам. Main проверяет источник IPC (конкретный WebContents, его главный frame и локальный origin), типы аргументов и внешние ссылки. Встроенная навигация, webview, дополнительные окна и разрешения устройств заблокированы. Внешний браузер открывает только разрешённые страницы OpenRouter/ClippyJS. CSP разрешает API только на OpenRouter/OpenAI и Blob-аудио; dev-скрипты и стили разрешены для HMR. **Эта оболочка пока только для dev**, remote/production renderer URL не принимается.

## Что работает

- Браузерная XP-комната для предпросмотра, настоящее XP-окно Electron для локальной разработки и отдельный режим маскота на рабочем столе. В веб-версии меню «Пуск»/панель задач декоративные; в desktop используются настоящие функции ОС.
- **Clippy, Rover, Merlin**: оригинальные спрайт-листы и последовательности кадров из `clippyjs@0.1.0`.
- Состояния ожидания, размышления, реплики, обиды, ухода, выглядывания и грубого жеста.
- Автоматическое возвращение по таймеру; сообщения ушедшему маскоту заставляют его выглянуть с коротким ответом. Во время паузы он иногда сам выглядывает с репликой, реже — с грубым жестом (не в мягком режиме). Можно позвать обратно или извиниться. Просроченные таймеры после сна/заморозки окна не отменяют возвращение.
- Кнопки для ручной проверки поведения и три уровня дерзости. Мягкий режим запрещает грубый жест, в том числе полученный от модели.
- Демо-диалог без ключа: **это локальные заготовленные реплики, а не LLM**.
- OpenRouter: свой API-ключ, произвольный ID текстовой модели, последние 20 сообщений как контекст, лимит ответа и таймаут 45 секунд.
- Понятные ошибки авторизации, баланса, модели, лимита запросов и сети; защита от устаревших ответов после смены персонажа/настроек/сброса диалога.
- **Настройки → Голос**: системный TTS и опциональный OpenAI TTS, отдельные тембры персонажей, скорость, последовательная очередь без наложения, остановка/отмена. Динамик по умолчанию выключен. Системные голоса зависят от ОС; некоторые используют облако. OpenAI TTS — AI-голоса с отдельным ключом и платными запросами, не оригинальные голоса маскотов.
- **Настройки → Поведение**: накопительное раздражение/остывание, тихие часы, запрет грубых жестов, отключение самостоятельных реплик, opt-in память отдельных диалогов в текущей сессии. «Без подколов» локально переключает мягкий режим без запроса модели.
- Плеер оригинальных кадров поддерживает вероятностные ветвления, `exitBranch`, `useExitBranching`, слои, завершение текущего действия при смене состояния, ограничение циклов и reduced-motion.
- Адаптивный интерфейс; на телефоне маскот и чат переключаются вкладками.

### Подключить OpenRouter

1. Открыть **Настройки**.
2. Выбрать **OpenRouter**, вставить ключ с [openrouter.ai/keys](https://openrouter.ai/keys).
3. Указать доступный ID текстовой модели (по умолчанию `google/gemini-2.5-flash`). Доступность и тариф определяются OpenRouter.
4. Нажать **Применить**, затем отправить сообщение.

«Ключ задан» означает только наличие ключа, не успешную авторизацию. Проверка происходит при запросе. Запросы могут быть платными. Реальный запрос с пользовательским ключом в этой среде не проверялся; транспорт и обработка ответов проверены с подставными ответами.

### Настроить голос

По умолчанию используется системный TTS. Открой **Настройки → Голос**, выбери голос каждому маскоту и скорость, примени настройки, затем включи динамик. Если русских голосов нет — установи языковой пакет ОС или выбери доступный голос вручную.

Для опционального облачного варианта выбери **OpenAI TTS**, введи отдельный ключ OpenAI и примени. Ключ OpenRouter не подходит. Используется `tts-1`; после включения динамика новые реплики вызывают **платные** запросы. Не более 30 новых сетевых попыток на сессию (ошибки тоже считаются), до 2500 символов на запрос. Кэш до 20 аудио/20 МиБ в памяти, очищается при смене настроек; лимит попыток при этом не сбрасывается. Денежные расходы контролируются в аккаунте провайдера. Реальные платные вызовы не проверены; транспорт, ошибки и отмена покрыты подставными ответами.

При наличии событий `word` у системного голоса текущее слово подсвечивается в облачке, в том числе в прозрачном режиме. При отмене подсветка сбрасывается; запоздавшие события игнорируются. Если ОС не выдаёт границы слов, подсветки нет. У используемого OpenAI TTS нет таймингов слов — они **не выдумываются**. Это не фонемная артикуляция и не оригинальные голоса маскотов.

### Конфиденциальность

Оба ключа, настройки чата/голоса, истории и кэш аудио находятся **только в памяти текущей вкладки/renderer**. Исключение — несекретные размеры и расположение desktop-окна, описанные выше. Нет localStorage, sessionStorage, аналитики, серверного хранения или логирования ключей. После перезагрузки всё, кроме геометрии окна, сбрасывается.

Ключ OpenRouter отправляется только к `https://openrouter.ai/api/v1/chat/completions`. В live-режиме сообщения передаются OpenRouter и выбранному провайдеру модели. Если явно выбран OpenAI TTS, его **отдельный** ключ и текст реплики отправляются только к `https://api.openai.com/v1/audio/speech`; системный TTS может передавать текст поставщику голоса ОС. Память сессии выключена по умолчанию и не записывается на диск.

Это BYOK-клиент, не место для размещения общего секретного API-ключа. Для публичного сервиса с общим ключом потребуется отдельный backend с авторизацией, лимитами и секретами на сервере.

## Честно об ограничениях

- **Это исходники и dev-запуск**, а не готовый `.exe`. Live preview показывает браузерную версию, не реальное окно ОС. Desktop запускается отдельно на компьютере; интеграция с ОС требует нативной проверки. Прозрачный режим добавлен в исходники, но не проверен на Windows; автозапуск пока не реализован.
- **Courtney и Earl пока недоступны.** В использованном наборе ClippyJS их нет. Нужны проверенные исходники и разрешение на использование. В интерфейсе это явно обозначено.
- Средний палец — **новая SVG-накладка** с отдельным оформлением для Clippy, Rover и Merlin, уход/выглядывание — новые CSS-переходы. Не выдаются за оригинальные кадры Microsoft.
- Анимация разговора использует оригинальные `Explain`/`Acknowledge` и удерживается во время аудио, но **не синхронизирована с фонемами**. Граф ветвлений/выходов поддерживается с ограничителями времени; это не полноценная реализация всего Microsoft Agent. Встроенные звуковые эффекты намеренно не воспроизводятся.
- Тон и решения LLM вероятностные. JSON проверяется, неизвестные состояния отбрасываются, уход ограничен 60 секундами; обычный текст тоже поддерживается.
- По умолчанию смена персонажа начинает новый диалог. При включённой памяти сессии восстанавливаются отдельные разговоры (до 100 сообщений на персонажа). После перезагрузки всё забывается; долговременной памяти нет.
- Маскоты не читают экран, файлы, клавиатуру или содержимое других приложений. Единственное исключение для управления окном: при явно включённом click-through основной процесс локально проверяет текущую позицию курсора. Она не записывается, не передаётся renderer/LLM и не используется в характере маскота. При выключенном режиме этого опроса нет.

## Ресурсы и авторство

`scripts/prepare-agents.mjs` перед dev/build извлекает PNG и JSON трёх персонажей из фиксированной версии ClippyJS в игнорируемую папку `public/agents/`. В production это обычные локальные статические ресурсы, без CDN и тяжёлых base64 JavaScript-бандлов. В Git бинарные спрайт-листы не дублируются.

Лицензия кода ClippyJS — MIT, но **она не распространяется на изображения, имена и другие ресурсы агентов**. Они принадлежат Microsoft и соответствующим правообладателям. Перед публичным или коммерческим распространением необходима отдельная проверка прав. См. [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md).

## Статус по пунктам

Подробно: [docs/ROADMAP.md](docs/ROADMAP.md). Нативная проверка: [docs/WINDOWS-QA.md](docs/WINDOWS-QA.md).

1. **Desktop** — XP-окно и прозрачная поверхность с безопасным возвратом готовы в исходниках; экспериментальный opt-in click-through добавлен; реальное Windows QA и opt-in автозапуск остаются открытыми.
2. **Анимации** — граф/выходы/слои и три оформления нового SVG-жеста реализованы; фонемная артикуляция и оригинальные дополнительные покадровые жесты остаются.
3. **Courtney/Earl** — заблокировано отсутствием проверенных пакетов ресурсов и сведений о правах. Замены не подставлены.
4. **Голоса** — системный и опциональный облачный TTS, очередь, отмена, кэш, лимит попыток и подсветка слов по событиям ОС добавлены; нужно прослушивание на целевой ОС и проверка реального провайдера.
5. **Поведение** — накопительное раздражение, остывание, настройки границ, тихие часы, память сессии готовы. Долговременную память/наблюдение за экраном не добавляли.
6. **Упаковка** — только в конце. Production-сборка, `.exe`, установщик и подпись на этом этапе не запускались.
