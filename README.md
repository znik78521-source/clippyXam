# clippyXam 0.7.0 — нейрохам, NT Portable

Минимальный серый NT-интерфейс: оригинальные Clippy/Rover/Merlin, реплика, поле Enter, микрофон и настройки. Шутливый грубый персонаж, не системный администратор: не читает экран/файлы и не выполняет угрозы «снести Windows».

## Запуск без установки

[GitHub Releases](https://github.com/znik78521-source/clippyXam/releases): в Assets скачай `clippyXam-0.7.0-win-x64-portable.exe`, не Source code ZIP. Windows 10/11 x64. Node.js, npm и установщик не нужны. Подробности: [PORTABLE-RU.md](PORTABLE-RU.md).

Exe самораспаковывается во временную папку, данные хранятся рядом в `clippyXam-data`. Запускай из папки с правом записи, без администратора. Сборка не подписана; сверяй источник/SHA-256, не отключай защиту Windows вслепую. Это предварительная версия для тестирования.

## Новое в 0.7.0

- **Автозапуск при входе в Windows**: Настройки → Подключение, выключен по умолчанию. Только однофайловый portable; регистрируется стабильный путь EXE с `--autostart`, не временная распаковка. Не требует администратора. При переносе/удалении сначала отключить; после переноса включить заново.
- **Настройки сохраняются** в `clippyXam-data/preferences.json`: персонаж, модель, характер, голос/скорость, тихие часы, переключения. Ключи — только в отдельном зашифрованном vault; переписка/черновик/аудио не пишутся. Платный TTS не восстанавливается автоматически. Виджет после запуска открывается вручную.
- **Пропуск кликов в виджете**, opt-in: альфа-маска текущего оригинального sprite-кадра, защита рамки/ввода/кнопок. Во время вращений, выглядывания и сценок — консервативная область персонажа; не обещаем pixel-perfect на любых DPI/трансформациях. При зависании, неверной карте, скрытии/сворачивании отключается. Восстановление через трей/Esc/рамку. Координаты мыши остаются только в main и не попадают в чат.
- **Движение в такт Piper**: анализ громкости PCM WAV, отсчёт по `Audio.currentTime`, только во время воспроизведения. Остановка/отмена/пауза сбрасывает движение; reduced-motion отключает. Это ритмическая анимация оригинального спрайта, **не новые фонемы/формы рта**.

## Сетевое исправление из 0.6.1

Portable больше не отправляет OpenRouter-запросы из renderer с `clippyxam://` origin: чат и каталог используют ограниченный owner-only IPC → Electron `net.fetch`. Только два фиксированных HTTPS endpoint, без произвольных URL/редиректов; бесплатность повторно проверяется в main. Не отключаются CORS, sandbox или проверка сертификатов. Используются сетевые настройки Chromium/Electron, включая системный прокси.

DNS/TLS/proxy/обрыв теперь показываются отдельными безопасными кодами без ключей/текста/сырых ошибок. Такие сбои останавливают перебор, поскольку все модели находятся на одном API-хосте. Отмена/таймаут доходят до main; число активных запросов и размеры ограничены.

Прежний smoke с `page.route` проверял лишь подставной ответ, не реальное соединение. Новый обязательный release gate из packaged EXE: живой публичный каталог HTTP 200 и запрос с заведомо неверным тестовым ключом HTTP 401; затем native mock-чата/DPAPI/виджета и запуск portable. **Это не тест генерации с действующим пользовательским ключом и не доказательство причины сетевого сбоя на его компьютере.**

## Чат и ключ

- Настройки → Подключение → **Бесплатная модель**: раскрываемый список с обновлением из публичного каталога OpenRouter. Только текстовые `:free` с нулевыми ценами ввода/вывода/запроса. Компактные модели (до 8B, эвристика по имени) идут первыми, большие — резерв. Это не замер скорости: очереди и доступность меняются. Без каталога используется встроенный список.
- По умолчанию автовыбор: компактные → резерв → `openrouter/free`. Ручной выбор всегда пробуется первым. При 400/404/408/429/5xx, таймауте модели, пустом/неправильно-языковом ответе — следующая бесплатная модель. До **4 разных ID**, до **9 секунд** на попытку; общий watchdog 45 секунд. Отмена останавливает цепочку. 401/402/403 не перебираются. Fallback можно выключить; общий лимит аккаунта смена модели не обходит.
- Исправлена совместимость формата: нет принудительных reasoning/temperature, приветствие ассистента не отправляется первым; после 400 следующая модель получает сокращённый контекст без system-role. Нулевые ограничения цены сохраняются всегда, платного fallback нет. Ответы короткие, JSON извлекается без служебных полей.
- Повторы расходуют бесплатную квоту. Текст может попасть нескольким провайдерам с разными правилами хранения/обучения — не отправляй секреты. Каталог запрашивается **без API-ключа**. Конкретную причину 400 у пользователя без ответа API подтвердить нельзя; live-запросы с его ключом не выполнялись.
- При ошибке текст остаётся в поле; новые правки не затираются. Неуспешный запрос убирается из контекста. История — RAM, до 20 последних сообщений отправляются модели.
- Ключ OpenRouter в Windows сохраняется **зашифрованным через Electron safeStorage/DPAPI**, привязанным к учётной записи/компьютеру. Без доступного шифрования — только RAM, никогда plaintext fallback. В браузере ключ остаётся только в RAM. Удаление — в настройках подключения. После переноса portable ключ может потребоваться ввести заново, создавать новый необязательно.

## Голос

**Piper / Denis (русский)** включён по умолчанию в portable. Движок внутри exe, голос автоматически скачивается один раз (63 МБ) с публичного Hugging Face в `clippyXam-data/voices/denis-v1`. Закреплены ревизия/размеры/контрольные суммы; повреждённые файлы не запускаются. Далее озвучка локальная: текст не отправляется на сервер, голоса Windows и API-ключи не нужны. Один голос для трёх персонажей; скорость настраивается. При ошибке скачивания — повтор в настройках голоса.

Системный TTS и отдельно подключаемый **платный OpenAI TTS** остаются альтернативами. Ключ OpenAI — только RAM. Микрофон — другая функция: экспериментальный System.Speech ru-RU, требующий совместимого установленного движка. Запасной путь: поле ввода → Win+H. Это не функция озвучки Piper.

## Поведение и анимации

По умолчанию жёсткий комедийный характер с матом. «Без подколов» или «Мягко» отключают хамство/жесты. Есть раздражение, остывание, уход/возврат, отдельное выглядывание с жестом, тихие часы и opt-in память диалогов персонажей.

Восемь новых сценок: бита с замахом и трещинами; закапывание; решётка и пиксельное рассыпание; огнемёт; прыжки со звёздочками; шуточное форматирование; фальшивый синий экран; фальшивое обновление. Просмотр — **Настройки → Поведение → Просмотр мемной сценки**. Всё ограничено окном, не перехватывает клики и не вызывает системные команды. Есть reduced-motion режим.

«Незаконная реплика» — игровая проверка слов в предыдущем ответе маскота, не юридическая оценка. При совпадении и обвинении пользователя шанс ареста — 90%. Без соответствующей предыдущей реплики принудительного ареста нет. Случайные сценки ограничены раздражением и паузой; мягкий режим, тихие часы и запрет жестов их отключают.

Новые сценки/рука — авторские SVG/CSS, не оригинальные кадры Microsoft. Courtney/Earl и фонемная артикуляция не готовы. Оригинальные ресурсы трёх доступных персонажей — из ClippyJS; права на artwork отдельны от MIT-кода. См. [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Окно и безопасность

Виджет включается в настройках, имеет те же стилизованные кнопки. Основное окно остаётся владельцем ключей/чата/озвучки. Пассивный renderer получает только разрешённый снимок (включая ограниченный черновик последней неуспешной отправки), без ключей и истории. Есть восстановление через рамку/Esc/трей; click-through выключен по умолчанию и включается отдельно в настройках.

Electron sandbox/contextIsolation включены. IPC проверяет отправителя/главный frame/локальный URL и значения. Production загружает только `clippyxam://bundle/`; remote renderer URL из окружения игнорируется. Piper вызывается фиксированным exe без shell, текст — stdin, размер/время/отмена ограничены. Ключевое хранилище доступно только владельцу, не поверхности виджета.

## Разработка

Для исходников нужен Node.js 22.12+:

```sh
npm ci
npm run verify
npm run dev                   # browser preview
npm run desktop:dev           # Electron + Vite
npx playwright install chromium
npm run test:e2e
npm run portable:win          # Windows: готовит Piper, собирает portable
```

`npm run verify` — типы, логика, mock-контроллеры и аудит спрайтов. Windows CI дополнительно синтезирует настоящий русский WAV, запускает packaged-приложение и сам portable. [TEST-REPORT.md](docs/TEST-REPORT.md), [WINDOWS-QA.md](docs/WINDOWS-QA.md). Проверки в runner не заменяют прослушивание, реальный микрофон, GPU/DPI и мониторы пользователя. Устаревшие исходные ZIP удалены из рабочей ветки. Готовые бинарники — только в GitHub Releases.
