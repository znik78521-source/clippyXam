# clippyXam — запуск для проверки на Windows

Это **архив исходников тестовой версии 0.1.0**, не готовый `.exe` и не установщик. Компиляция приложения ещё не выполнялась. В архиве нет ключей, переписок, `node_modules` или чужого Linux-runtime.

## Как запустить

1. Нужна **Windows 10/11** и **Node.js 22.12 или новее** (вместе с npm). Скачать Node.js можно с https://nodejs.org/ . После установки заново открой окно запуска.
2. **Распакуй весь ZIP**, например в `Документы\clippyXam-test`. Не запускай `.cmd` прямо из окна архиватора; папка должна быть доступна для записи.
3. Дважды нажми **`START-WINDOWS.cmd`**. Права администратора не нужны.
4. При первом старте дождись установки зависимостей через `npm ci`. Нужен интернет к npm и GitHub: скачивается готовый Electron runtime для твоей ОС. Это **не компиляция clippyXam**. Установка выполняет стандартные install-скрипты зависимостей; при обновлении lock-файла/версии Node/архитектуры повторится.
5. Откроется маленькое XP-окно. Начни с **демо-режима без ключей**. Он использует заготовленные реплики, не настоящую нейросеть.
6. Оставь консоль запуска открытой. Для выхода нажми **× в XP-окне** или **Выйти в трее**. В прозрачном режиме Alt+F4 лишь возвращает XP-окно.

Если предпочитаешь терминал, открой его в распакованной папке:

```powershell
npm ci
npm run desktop:dev
```

Сервер доступен только локально на `127.0.0.1`; начинает с порта 5174 и при занятости выбирает следующий. Повторный запуск должен вернуть существующее окно вместо второго маскота. Это поведение ещё нужно подтвердить на настоящей Windows.

## Что проверить за первый проход

- **XP-окно:** перетаскивание, размер, мини/полный режим, сворачивание, булавка «поверх окон».
- **Чат:** «Привет», обычный вопрос, «без подколов». Кнопка «Стоп» отменяет ожидание ответа.
- **Персонажи:** Clippy, Rover, Merlin. Смена отменяет старый ответ/звук. Память отдельных разговоров включается в «Настройки → Поведение».
- **Уход:** попросить уйти или нажать кнопку демонстрации, написать во время паузы, позвать обратно, дождаться автоматического возвращения.
- **Голос:** «Настройки → Голос», выбрать установленный русский системный голос, включить динамик. Проверить «Стоп голос». Если голосов нет, нужен языковой пакет ОС. Системный голос может пользоваться сетью своего поставщика.
- **Прозрачный режим:** «Вид → Маскот на рабочем столе». Проверить ввод, смену персонажа, остановку голоса и возврат кнопкой XP/Esc/через трей.
- **Пропуск кликов:** включать отдельно кнопкой мыши в прозрачном режиме. Это экспериментальная проверка прямоугольных областей, не точная пиксельная маска. Держи трей доступным. При зависании интерфейса режим должен отключиться сам.
- **Выход:** закрыть XP-окно, убедиться, что голос и dev-сервер остановились.

Полная проверка: [docs/WINDOWS-QA.md](docs/WINDOWS-QA.md). Самая важная часть — прозрачность, фокус, разные DPI мониторов и системные голоса: Linux/browser-тестами это не подтверждено.

## Подключить настоящую модель

«Настройки → OpenRouter» → свой ключ → ID доступной модели → «Применить». Ключ не отправляй мне и не включай в скриншоты. Запросы могут быть платными. Отмена на клиенте не гарантирует отмену списания у провайдера.

Для OpenAI TTS нужен **отдельный ключ OpenAI**; это необязательная платная озвучка. Для первого теста она не нужна. Оба ключа и диалоги хранятся только в памяти сеанса, после закрытия исчезают.

## Проверка исходников без компиляции

Дважды нажми **`CHECK-WINDOWS.cmd`**. Он при необходимости установит зависимости, затем проверит типы, логику, контроллеры окна, запуск и оригинальные ресурсы. Не запускает приложение, не обращается к платным API, не делает `.exe`. Не запускай параллельно с первой установкой через START.

То же вручную после `npm ci`:

```powershell
npm run verify
```

Браузерные автотесты — отдельно, при желании (дополнительная загрузка Chromium):

```powershell
npx playwright install chromium
npm run test:e2e
```

## Если не запускается

- **Node не найден / старая версия:** установить актуальный Node.js, проверить `node -v`, закрыть и снова открыть `.cmd`.
- **Ошибка загрузки npm/Electron:** проверь интернет к npm/GitHub, сообщения антивируса и свободное место. Не отключай антивирус вслепую. Повторный START повторит незавершённую установку.
- **Ранее установка была с пропуском runtime:** START ставит его автоматически; вручную убери `ELECTRON_SKIP_BINARY_DOWNLOAD`, выполни `npm rebuild electron --ignore-scripts=false`.
- **Нет звука:** включён ли динамик, установлен ли русский голос, не действуют ли тихие часы? Не переключайся на платный TTS просто для диагностики.
- **Чёрный фон / не ловит клики в прозрачном режиме:** верни XP через трей или повторный START, отключи экспериментальный пропуск кликов. Запиши версию Windows, DPI и симптомы.
- **Окно за экраном:** закрой приложение, переименуй только `window-state.json` в папке `clippyXam` внутри `%APPDATA%`, затем запусти снова. Файл содержит геометрию, не ключи. Если такой папки нет, не удаляй папки других Electron-приложений.

## Честный статус

Готово в исходниках: XP-окно, три маскота, OpenRouter, уход/возврат/характер, системная и опциональная облачная озвучка, прозрачный режим и быстрые команды. Автотесты перечислены в [docs/TEST-REPORT.md](docs/TEST-REPORT.md).

**Не завершено / не подтверждено:** настоящий Windows-прогон; Courtney/Earl (нет проверенных ресурсов); точная артикуляция по фонемам; оригинальный покадровый грубый жест (сейчас новая SVG-накладка); автозапуск; production-упаковка и подпись. Проверка прав на оригинальные Microsoft-ресурсы перед распространением также остаётся открытой. Ресурсы трёх персонажей извлекаются из установленного ClippyJS при запуске, не вложены в ZIP как отдельные спрайт-листы. См. THIRD_PARTY_NOTICES.md.
