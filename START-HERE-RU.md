# clippyXam 0.2.0 — тест исходников на Windows

**Это новый NT/minimal-архив, не предыдущая XP-версия и не готовый exe.** Упаковка отложена до твоего теста и разрешения.

## Запуск

1. Windows 10/11; установи **Node.js 22.12+** с npm: https://nodejs.org/ . Node нужен сейчас для исходников, не отдельно для будущего упакованного приложения.
2. Распакуй **весь ZIP** в новую доступную для записи папку. Не запускай из архиватора и не смешивай файлы с предыдущей версией.
3. Открой **START-WINDOWS.cmd**, без администратора. Первый запуск устанавливает зависимости из lock-файла и Electron с npm/GitHub. Это не компиляция clippyXam.
4. В сером окне введи свой ключ OpenRouter. Получить: https://openrouter.ai/keys → Create Key. Ключ проверится первым сообщением; он не сохраняется после закрытия. Демо нет.
5. Напиши сообщение, нажми **Enter**. По умолчанию используется **openrouter/free**, платный fallback заблокирован. При лимите/ошибке будет сообщение, не подмена платной моделью.
6. Консоль оставь открытой. Выход — × в рамке или «Выйти» в трее.

Ручной запуск из папки: `npm ci`, затем `npm run desktop:dev`. Локальный сервер выбирает свободный порт начиная с 5174 и закрывается вместе с приложением.

## Что проверить

- Серая NT-рамка: перенос, resize, сворачивание/разворачивание, закрытие. Начальный размер 360×460, минимум 320×400 (старый профиль может восстановить старые размеры).
- Ввод ключа при каждом новом запуске, Enter, ответ и отмена ожидания. Ошибка 429 не должна включать платную модель.
- Шестерёнка: выбор Clippy/Rover/Merlin, дерзость, настройки голоса/поведения. Courtney/Earl пока недоступны.
- **Настройки → Виджет на рабочем столе**: прозрачность, ввод, те же кнопки рамки. Настройки временно возвращают основное окно; отмена снова открывает виджет. Кнопка восстановления/Esc/трей возвращают обычное окно. × завершает, Alt+F4 в виджете только возвращает владельца.
- Микрофон: текст должен появиться в поле, а не отправляться сам. Повторное нажатие отменяет. **Нужен совместимый русский System.Speech-распознаватель**; обычного русского языка Windows/Win+H может быть недостаточно. Если недоступен — пришли сообщение ошибки, не устанавливай случайные пакеты и не отключай защиту Windows. Реальный Windows-ввод ещё не проверен.
- Озвучка отдельно: **Настройки → Голос → Озвучивать ответы**, системный голос. OpenAI TTS не нужен для проверки: это явно подключаемая платная опция с отдельным ключом.
- Уход, выглядывание, возвращение по таймеру; «без подколов» включает мягкий режим. Наличие нового жеста зависит от настроек и ответа модели; накладка не оригинальная анимация Microsoft.

## Проверки и проблемы

**CHECK-WINDOWS.cmd** проверяет исходники без сборки и API-вызовов (`npm run verify`). Не запускай параллельно с первой установкой. Браузерные тесты отдельно: `npx playwright install chromium`, `npm run test:e2e`.

Если Node не найден — проверь `node -v` и заново открой консоль. Если Electron не скачался — проверь доступ к npm/GitHub, антивирус и свободное место; не отключай защиту вслепую. После установки с пропуском runtime убери `ELECTRON_SKIP_BINARY_DOWNLOAD`, выполни `npm rebuild electron --ignore-scripts=false`.

Если нет звука — выбран ли доступный голос, включена ли озвучка, не действуют ли тихие часы? Если виджет чёрный/не принимает ввод — верни окно через трей или повторный START. Пропуск кликов в этом минимальном UI не включается; прозрачные области могут перехватывать клики.

Если окно за экраном — после закрытия переименуй только `window-state.json` в `%APPDATA%\clippyXam`, если такая папка существует. Не удаляй данные чужих Electron-приложений. В файле только геометрия/режим, не ключи.

Полный чек-лист: [docs/WINDOWS-QA.md](docs/WINDOWS-QA.md). Результаты автоматических проверок: [docs/TEST-REPORT.md](docs/TEST-REPORT.md). Отзыв: [docs/FEEDBACK-TEMPLATE.md](docs/FEEDBACK-TEMPLATE.md). **Не присылай ключи и личную переписку.**

Остаются незавершёнными Courtney/Earl, фонемная артикуляция, оригинальный грубый жест, автозапуск, native Windows QA и проверка прав перед распространением. Исправление интерфейса не делает эти пункты готовыми.
