# Источники новых рисунков и проба инерции

Механика одобрена пользователем, затем добавлен заметный наклон на средней скорости. В 0.9 перенесена в основной renderer Скрепки и пассивный виджет. Исходные PNG здесь, runtime-версии с альфой — `public/authored/clippy` и manifest с хешами. Скрипт `prepare-inertia-assets.py` воспроизводит удаление хромакея; Python/Pillow/numpy не нужны пользователю portable.

`index.html`/`inertia-demo.ts` — отдельная интерактивная проба: `npx vite --config artwork/prototype/vite.config.ts`. GIF-записи и старый эксперимент morph не коммитятся как runtime-ресурсы.

Новые собственные рисунки: neutral, curious, impact-left, impact-right. Анимация сочетает их с локальным изгибом по spring/inertia-модели. Это не готовые Agent-кадры и не поворот всей картинки; но и не утверждение о независимой перерисовке всех промежуточных фаз. Правая ударная поза теперь отдельная, не зеркало левой. Вертикальные удары пока используют сжатие; собственные рисунки для них, Rover/Merlin и расширенные сцены ещё предстоят.

Скорость native-окна приходит в DIP/s, ограничена, без координат экрана. Умеренный разгон даёт заметный наклон, резкий — столкновение. Пауза, отдача, затухание; сброс на resize/скрытие/максимизацию и защитное завершение потерянного движения. При печати — прежняя слабая отдельная вибрация. Reduced motion останавливает физику.

Генерации не являются официальными ресурсами Microsoft. Права на дизайн персонажей не объявляются принадлежащими проекту. Совпадение рисовки с оригиналом не объявляется абсолютным.
