# Новые сценки Скрепки

Четыре AI-generated рисунка по референсу нового neutral: windows-armed/windows-punchline и bat-windup/bat-strike. Не исходные Agent-кадры. Правая поза биты исправлена на отдельный горизонтальный follow-through, а не поворот картинки.

`python prepare.py` (Pillow, numpy) удаляет магентовый фон и сохраняет общий canvas для регистрации поз, обновляет manifest с хешами. Пользователю portable Python не нужен. Runtime `authored-scenes.ts` использует смену новых ключевых поз, локальный изгиб и короткие canvas-трещины; полная независимая отрисовка каждого промежуточного кадра не заявляется.

Ни рисунки, ни comedy director не выполняют команды ОС. Визуальные эффекты ограничены canvas маскота. Reduced motion отключает их. Политика шуток в `comedy.ts`: явный запрос либо успешные короткие ответы, двойной cooldown, запрет в мягком режиме. Новые Rover/Merlin и оставшиеся сцены не считаются готовыми.
