# Архивы исходников для Windows

- **clippyXam-0.2.0-windows-source.zip** — текущая NT/minimal-ревизия: обязательный ключ, бесплатный чат, виджет в настройках, экспериментальный голосовой ввод. Начать с START-HERE-RU.md внутри архива. Не exe.
- clippyXam-0.1.0-windows-source.zip — старая XP/demo-ревизия, оставлена для старых ссылок. Новых исправлений не содержит.

Распаковывать в отдельную папку, не смешивать версии. Рядом с каждым ZIP — SHA-256; внутри — SOURCE-MANIFEST.json. Node.js 22.12+ нужен для теста исходников. Упаковка приложения отложена до согласования.
