Ближайший шаг: [WINDOWS-QA.md](WINDOWS-QA.md), исправления по результатам, проверка portable на пользовательской машине и проверка прав. Нет обещания, что недостающие ресурсы или native-распознавание решаются одним проходом.

Основное окно остаётся единственным владельцем ключей/истории/TTS. Пассивное окно получает ограниченные снимки состояния и разрешённые действия, не ключи/историю. Возврат через рамку/Esc/трей; готовность с таймаутом 15 секунд. Браузерный виджет не заменяет Windows-проверку.

## Анимации

`src/lib/animation.ts` — отдельный тестируемый плеер. Внутри графа сохраняется исходная длительность кадра (минимум 10 мс для защиты от нулевых циклов), но видимый результат ограничен частотой обновления браузера. `useExitBranching` удерживает последнюю видимую позу и не показывает конечный пустой sentinel. При смене действия запрашивается выход по исходным ветвям. Самая свежая заявка заменяет предыдущую.

Защита: одна операция графа за tick, без бесконтрольного наверстывания кадров после сна; 2-секундный предел выхода; ограничение числа шагов/длительности цикла. При плохом графе возможен принудительный переход — это сознательное исключение из плавности. Во время слышимой реплики поза разговора удерживается до завершения аудио; это **синхронизация активности, не артикуляция по фонемам**.

`npm run audit:agents` проверяет длительности и выход слоёв за пределы PNG и печатает SHA-256 исходных ресурсов. В ClippyJS: Clippy — 43 анимации/1233 кадра, Rover — 29/1106, Merlin — 73/945. Все кадры проверяются, но интерфейс пока использует подмножество действий.

SVG-жест теперь имеет три явно новых оформления: металлическая перчатка Clippy, шерстяная ладонь Rover, манжета со звездой Merlin. Это не дополнительные оригинальные Microsoft кадры.

## TTS и расходы

- По умолчанию системный голос, динамик выключен.
- Подсветка текущего слова идёт только по реальным `word` событиям системного драйвера; отмена и смена реплики сбрасывают её. Границы UTF-16 проверяются. Если ОС не выдаёт события, либо используется OpenAI без таймингов, подсветки нет. Фонемный lip-sync не реализован.
- OpenAI TTS выбирается явно; ключ отдельный, только в памяти. Endpoint фиксирован: `https://api.openai.com/v1/audio/speech`, модель `tts-1`, до 2500 символов.
- Не более 30 новых сетевых попыток на сессию, ошибки тоже учитываются; повтор из кэша не тратит попытку. Смена настроек не сбрасывает лимит; перезагрузка приложения сбрасывает.
- Кэш: до 20 Blob / 20 МиБ, только оперативная память. Очистка при смене настроек и закрытии; ObjectURL отзывается после воспроизведения.
- Очередь: текущая реплика + до трёх ожидающих. Сообщение/маскот/настройки/выключение звука/тихие часы отменяют старую работу. Устаревший сетевой ответ не начинает говорить за другого персонажа.
- 45 секунд на TTS-запрос; 120 секунд на всю озвучку одной реплики. Нет автоматического платного fallback, фоновых тестовых запросов или общего серверного ключа.
- Реальная стоимость определяется провайдером. Лимит попыток — не денежная квота; следить за балансом нужно в аккаунте провайдера.

## Память и характер

Раздражение 0–100: настойчивые требования +14, оскорбления +28, обычное сообщение −3, благодарность −20, извинение/просьба прекратить подколы −40. Раз в 30 секунд −2, после паузы −25. При 85+ может включиться локальная 20-секундная пауза. Эти числа описывают комедийного персонажа, а не оценку пользователя.

Мягкий режим и выключенный грубый жест проверяются локально, не только промптом. Просьбы «без подколов», «без мата», «не издевайся» переключают мягкий режим и подтверждаются без запроса LLM. Это не универсальный классификатор любой формулировки; всегда доступны явные настройки.

Память сессии выключена по умолчанию. При включении — до 100 сообщений и значение раздражения отдельно у трёх персонажей в памяти renderer. Не сохраняется после перезагрузки. Выключение удаляет припаркованные диалоги. На сервер уходит только контекст выбранного персонажа при отправке в OpenRouter (до 20 последних сообщений).
