# Статус 0.5.0

## Реализовано и проверено автоматически

- Минимальная NT-оболочка и portable Windows x64 без Node.js/установщика.
- Бесплатный Liquid по умолчанию; ограниченный повтор пустого/неправильно-языкового ответа, извлечение текста из обрезанного JSON.
- Возврат неуспешного сообщения без затирания нового черновика; зашифрованный OpenRouter-ключ через Windows DPAPI.
- Отдельный виджет, восстановление и настройки; исправлено обращение к уничтоженному BrowserWindow при закрытии поверхности.
- Локальная русская озвучка Piper/Denis с автоматической загрузкой и проверкой модели; реальный синтез проверен на Windows runner.
- Раздражение, мягкий режим, уход/выглядывание/возврат, восемь авторских SVG/CSS-сценок. Угрозы Windows — только визуальная шутка.

## Следующий этап — обратная связь пользователя

Проверить скорость/русский текст живой модели, звучание на реальном устройстве, прозрачность/GPU/DPI, несколько мониторов и микрофон. Автотесты не заменяют этот проход. [Шаблон отзыва](FEEDBACK-TEMPLATE.md), [чек-лист](WINDOWS-QA.md), [отчёт](TEST-REPORT.md).
