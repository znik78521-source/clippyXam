# Проверки 0.7.0 — 15 октября 2026

Локально пройдено: типы, production build, 59 тестов логики, 65 Electron unit/mock, 5 launcher, 28 браузерных сценариев. **157 тестов**, плюс аудит 145 анимаций / 3284 кадров.

## Новый функционал

- Settings: whitelist без ключей/истории/черновиков, повреждённые/слишком большие JSON, очередность атомарных записей, диапазоны/enum, отказ от платного TTS при восстановлении. UI восстанавливает модель/персонажа/границы и не сохраняет секреты.
- Автозапуск: opt-in только по Apply, отмена не меняет его; стабильный путь portable EXE, аргумент --autostart; dev/unpacked/non-Windows запрещены; отказ ОС виден. Unit/mock не заменяет реальный вход пользователя в Windows.
- Клики: маска альфа-канала текущего оригинального кадра, прозрачные/непрозрачные пиксели, отрицательные координаты монитора, защищённые полосы, bounds/размеры/типы данных. Виджет публикует действительную маску кадра, показывает fail-safe ошибку, не получает координаты мыши/ключи.
- Речь: PCM16 WAV envelope по отсчётам, выбор уровня по времени; malformed/unsupported audio не ломает воспроизведение; отмена сбрасывает уровень и игнорирует поздние кадры. Reduced motion выключает движение. Это не phoneme lip-sync.
- Сохранены тесты native OpenRouter, free-only fallback, DPAPI, голоса, черновика и восьми сценок.

## Windows gate

Новая сборка ожидает CI. Обязательны live-каталог OpenRouter 200 и invalid-key POST 401 из packaged EXE, реальный синтез Piper, DPAPI/settings-file, виджет с включённым pointer controller, перезапуск с предпочтениями, запуск самого portable и чтение его startup-capability без записи автозапуска на runner.

Это не генерация с действующим пользовательским ключом. Не проверены физические клики/вход в Windows, реальные микрофон/колонки, GPU/DPI/несколько мониторов. Неподтверждённые ресурсы и ограничения отдельно записаны в ROADMAP.md.
