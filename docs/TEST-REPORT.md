# Проверки 0.9.0 — 15 октября 2026

Локально: типы, production build, **183 теста**: 70 logic, 71 Electron unit/mock, 5 launcher, 37 browser. Весь браузерный набор прошёл после стабилизации часов прототипа; его два теста отдельно повторены по три раза (6/6). Аудит исходных ресурсов сохраняется (145 анимаций / 3284 кадра); они не используются новым renderer Скрепки.

Проверяются:
- Инерция от изменения скорости, торможение вперёд, средний заметный наклон без удара, сильное движение и четыре стороны, контакт/отскок/затухание, reduced motion.
- Native-пакеты: ограничение ±4000 DIP/s, отсутствие координат, coalescing/stop, reset при изменении layout. Локальные unit-проверки и реальная Windows-проверка описаны ниже.
- Новая Скрепка в owner/widget, новая alpha-mask, физическое изменение пикселей, самостоятельные Curious/Stretch без загрузки исходных Clippy-кадров, тряска каждого ввода, preview и явный legacy fallback. Переключатель сохраняется.
- Прежние проверки free-only chat, длинных реплик, ошибок/черновиков, autosave, Piper, privacy и fail-safe сохранены. Rover/Merlin и legacy-Clippy тестируются отдельно.

# Проверки 0.8.0 — 15 октября 2026

Локально прошли типы, production build, **164 теста**: 60 logic, 68 Electron unit/mock, 5 launcher, 31 browser. Аудит ресурсов: 145 анимаций / 3284 кадра.

## Регрессии из отзыва

- Original idle-паки содержат начальные ветви с 85–97% вероятностью пропуска всего действия. Явный запрос нового director обходит только эту начальную ветвь, остальные кадры/ветвления сохранены; отдельный regression-test.
- Имена всех новых оригинальных mappings существуют в поставляемых ресурсах. Для каждого персонажа браузер проверяет несколько разных idle-действий и реальные изменения пикселей canvas.
- Четыре направления движения имеют разные canvas-изображения без CSS-поворота. Каждый отдельный ввод вызывает короткое подрагивание; reduced motion подавляет реакции.
- Preview использует оригинальные действия; старых SVG-сценок/руки нет. Уход/возврат не заменяют полный ответ таймером/штатной фразой.
- Длинная реплика >4000 символов сохраняет абзацы и конец, доступна прокрутка. Запрос использует 2048 токенов; стандартный router первый, Liquid исключён.
- Сетевая диагностика не появляется в облачке. Ошибки сохраняют сообщение и новые правки; проверяются native DNS/отсутствие повторов, zero-price и отдельная диагностика.
- Autosave без Apply; проверены последовательные медленные записи, новая правка во время записи, flush по Escape, ошибка диска и повтор, сохранение без секретов. Миграция старых предпочтений на router/1.25, последующий ручной выбор не сбрасывается.
- Persistent Piper unit: два задания одним процессом, накопительная PCM-граница, stderr раньше/позже stdout, отмена владельцем/навигацией. Голосовой driver готовит следующий фрагмент до окончания первого, не теряет длинный текст. Представление ответа привязано к старту воспроизведения; stop не вызывает поздние callbacks.
- Сохранены проверки DPAPI, native network/IPC, launcher, alpha click-through и его fail-safe.

## Windows release gate — пройден

[CI 38700242101](https://github.com/znik78521-source/clippyXam/actions/runs/38700242101), **6 минут 41 секунда**, commit `57e67641d7a0994d5bae8bfe5ca0e093a3e54009`.

- Все 164 теста также прошли на Windows, EXE собран.
- Настоящий Piper: два задания одним процессом, смена скорости, отмена и успешный синтез после отмены. Для фиксированной тестовой реплики: первый синтез **902 мс**, повторный **487 мс**; длина WAV при обычной скорости **3.564 с**, при 1.25 — **3.100 с**. Три процесса всего: начальный, смена скорости, восстановление после отмены. Это измерение синтеза на runner, **не** время ответа OpenRouter или гарантия задержки на устройстве пользователя.
- Packaged EXE: живой каталог OpenRouter 200 / invalid-key POST 401 через IPC, DPAPI, UI-autosave и allowlisted файл, mocked chat, виджет/settings/restore/alpha, reload.
- Сам portable запущен и закрыт; startup-capability проверена без записи автозапуска на runner.
- Тест разнообразия idle дополнительно повторён локально трижды; исходные начальные skip-ветви 85–97% больше не подавляют явно запланированную анимацию.

Первый run 38698955208 остановился на устаревшем ожидании файла preferences.json до первого изменения настроек. Исправленный тест создаёт файл реальным UI-autosave; сетевые/голосовые gates не отключались.
