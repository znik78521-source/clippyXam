## Покрытие исправлений

- Пустые ответы: один повтор на той же бесплатной модели; нет повторов при 401/429 и после отмены.
- Обрезанный JSON и служебные поля не показываются как реплика; ответы с иероглифами повторяются вместо отображения.
- Неудачная отправка сохраняет черновик и удаляется из контекста; повтор не дублирует сообщение, новые правки не затираются.
- Зашифрованное хранение ключа, отказ от plaintext fallback, удаление, повреждение/ошибка расшифровки, последовательность записей.
- Восемь отдельных сценок, граница 90% для мемного ареста при наличии предыдущей грубой реплики, мягкий режим/паузы/тихие часы.
- Отдельное выглядывание с жестом, явный выбор локального русского голоса без системных голосов Windows.
- Просмотрены browser-кадры сценок 360×460; промежуточные снимки удалены, в поставку не включены.

## Чего эти проверки не доказывают

Нет live OpenRouter-запросов с пользовательским ключом, измерения скорости или гарантии качества Liquid. Нет прослушивания на колонках пользователя, реального микрофона, полного GPU/DPI/многомониторного QA. Микрофон System.Speech всё ещё требует совместимого ru-RU recognizer; он не заменён озвучкой Piper.

Остаются ограничения ресурсов Courtney/Earl, фонемной артикуляции, оригинальных Microsoft-кадров жеста, автозапуска, подписи и прав на artwork. Никаких настоящих операций удаления Windows сценки не содержат.

Старые XP/demo-сценарии и числа предыдущих версий не суммируются с результатами 0.5.0. Бинарники распространяются через GitHub Releases, не хранятся в рабочем дереве.
