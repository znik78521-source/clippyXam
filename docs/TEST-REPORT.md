## Покрытие нового чата

- Каталог без ключа: только бесплатные текстовые варианты с нулевыми ценами; платные, нетекстовые, дубликаты и некорректные записи исключены. При отказе каталога остаются встроенные варианты.
- Выпадающий список, ручной выбор первым, автовыбор компактных, отключаемое переключение, отдельный резерв free-router, максимум 4 разных ID.
- HTTP 400 → другой free-ID без system-role и принудительных optional-параметров. Удаление начального приветствия ассистента, объединение повторяющихся ролей; лимиты цены не снимаются. Сырые ошибки, ключи и тексты запросов в диагностике не выводятся.
- 404/408/429/500/503, HTTP-200 error-envelope, сетевой сбой, таймаут чтения тела → следующая модель; 401/402/403 останавливаются сразу. Общая квота не обходится.
- Отмена прекращает активный запрос и цепочку; поздние ответы не применяются. Пустой/неправильно-языковой ответ переключает модель. Обрезанный JSON извлекается без служебных полей.
- После полного отказа черновик остаётся, новые правки не затираются, повтор не дублирует сообщение в истории.
- Сохранены тесты DPAPI/owner-widget, русской локальной озвучки и всех восьми безопасных визуальных сценок.

## Ограничения

Нет живого OpenRouter-запроса с пользовательским ключом: конкретная причина его HTTP 400 не воспроизведена. Автотесты проверяют mock-ответы и совместимость собственного формата, не доступность/скорость/качество внешних моделей. 9 секунд — срок попытки, а не обещание времени ответа. Провайдеры могут хранить текст; переключение раскрывает его нескольким провайдерам.

Нет прослушивания на колонках пользователя, реального микрофона, полного GPU/DPI/многомониторного QA. Микрофон System.Speech требует ru-RU recognizer, не заменяется Piper. Courtney/Earl, фонемная артикуляция, оригинальные Microsoft-кадры грубого жеста, автозапуск и подпись не готовы. Бинарники только в GitHub Releases, не в рабочем дереве.
