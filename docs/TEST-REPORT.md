# Проверки 0.2.0 NT/minimal — 14 октября 2026

**Исходники, без production build, exe и запуска Electron GUI.** Среда: Linux, TypeScript, Node test runner, Chromium/Playwright. Тесты чата, речи и desktop используют подставные API/мосты, настоящих ключей нет.

| Проверка                          | Результат                                    |
| --------------------------------- | -------------------------------------------- |
| `npm run check`                   | TypeScript без генерации файлов — успешно    |
| `npm test`                        | 28 тестов логики — успешно                   |
| `npm run test:desktop`            | 33 unit/mock теста — успешно                 |
| `npm run test:launcher`           | 5 тестов запуска — успешно                   |
| `npm run audit:agents`            | 3 пакета, 145 анимаций, 3284 кадра — успешно |
| `npm run test:e2e -- --workers=2` | 15 браузерных сценариев — успешно            |

**Итого: 81 тест**, плюс проверка типов и аудит ресурсов. Прежние 27 UI-тестов XP/demo заменены 15 сценариями нового интерфейса; старые числа не суммируются с новой ревизией. Политики окон, IPC, snapshot stripping, восстановление и оставшийся выключенный click-through контроллер по-прежнему проверяются unit/mock, но их реальное нативное поведение не подтверждено.

## Что проверено в новом UI

- Keyless запуск/перезапуск → обязательное подключение, отсутствие ключа в localStorage; серая рамка, минимальный набор кнопок.
- Enter → один запрос openrouter/free, zero-price caps, latency preference, без ключа в JSON.
- Платный ID блокируется; 401/удаление ключа возвращают подключение; 429 без платного fallback/авторетрай.
- Настройки виджета, отмена с возвратом, caption controls, browser minimize/restore; native bridge вызовы, восстановление подключения при keyless widget-state.
- Отмена и поздний ответ, отдельные контексты персонажей, мягкий режим и таймер ухода/возврата.
- Browser SpeechRecognition mock: явное включение, вставка черновика без автоотправки, отмена/поздний результат, отсутствие распознавателя. Native dictation mock: фиксированная команда, ownership, отмена, ограниченный вывод, завершение renderer и ошибки.
- Системный TTS mock: включение и остановка без переключения на платную озвучку.
- Узкие окна 320×480 и 320×400: нет горизонтальной прокрутки, composer помещается. Визуально просмотрены скриншоты 360×460 с подключением, основным окном и прокручиваемыми настройками.

Найдены и исправлены горизонтальная прокрутка и обрезание composer в маленьком browser-окне: grid-треки теперь имеют нулевой минимальный размер.

## Как запускали

`npm run verify` и `CHROMIUM_PATH=/tmp/chromium LD_LIBRARY_PATH=/tmp/chromium-libs/lib npm run test:e2e -- --workers=2`.

Chromium был временной sandbox-зависимостью, не добавлен в package/lock/архив. Electron runtime в sandbox не загружался. На Windows использовать обычный npm ci, не переменную пропуска Electron.

## Не проверено / ограничения

- Реальная Windows, трей/прозрачность/GPU/DPI/фокус, многомониторность и реальное завершение системного процесса распознавания.
- Настоящий русский микрофон: System.Speech требует совместимого ru-RU recognizer; обычный языковой пакет или Win+H не гарантирует совместимость. Это экспериментальный путь, не обещание работы из коробки.
- Живой OpenRouter, доступность/качество/скорость бесплатных моделей и настоящая озвучка. Никаких оплаченных API-вызовов не было.
- Courtney/Earl, оригинальный грубый жест, фонемная артикуляция, автозапуск и права на распространение Microsoft artwork остаются незавершёнными.
- Установщик, exe, production frontend build, подпись и packaging не создавались. Source ZIP создаётся отдельно с CRC/SHA-256 манифестом и не является сборкой приложения.
