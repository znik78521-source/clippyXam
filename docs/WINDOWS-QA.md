# Проверка desktop на Windows — ещё не выполнена

Среда разработки не имеет Windows GUI. Ни браузерные тесты с подставным мостом, ни unit-тесты контроллера **не подтверждают** работу реального окна, трея, звука и DPI. Этот документ — инструкция для следующей нативной проверки, не отчёт о её успехе.

## До начала

- Windows 10/11, Node.js 22.12+, обычный `npm ci` без `ELECTRON_SKIP_BINARY_DOWNLOAD`.
- `START-WINDOWS.cmd` после распаковки или `npm run desktop:dev`; занятый 5174 автоматически заменяется следующим портом. Проверять исходники без `build`, упаковки или установщика.
- Для начала — демо-режим и системный голос. Платные ключи не нужны.
- Не включать автозапуск: для текущего dev-launcher он не реализован. Прозрачная поверхность добавлена в исходники, ниже — отдельный блок проверки.

## Окно и системная интеграция

- [ ] Первый старт: компактное окно 420×650, XP-рамка, без фальшивой панели задач.
- [ ] Перетаскивание за заголовок; кнопки не перетаскивают окно.
- [ ] Resize со всех краёв; минимальный размер 360×520; поле ввода и кнопки доступны.
- [ ] 100%, 125%, 150%, 200% DPI: надписи читаемы, рамка/спрайты не исчезают.
- [ ] «\_»: настоящее сворачивание, восстановление через панель задач.
- [ ] «□», двойной клик по заголовку, системное восстановление: состояние UI совпадает с ОС.
- [ ] Булавка: закрепление поверх других приложений и отключение без потери фокуса.
- [ ] «×» и Alt+F4: приложение завершается, dev-сервер останавливается, аудио не остаётся.
- [ ] «Вид → Скрыть в системный трей»: окно скрывается; клик/меню трея возвращают его.
- [ ] Повторный запуск: не создаётся второй помощник; первый получает фокус.
- [ ] Выход из трея завершает все процессы приложения и dev-сервера.
- [ ] Два монитора, включая отрицательные координаты; отключить внешний монитор: окно не теряется.
- [ ] Перезапуск: положение/размеры восстановились отдельно для полного и компактного режима.
- [ ] Повреждённый `window-state.json`: безопасные значения по умолчанию, без падения.

## Прозрачный маскот — ещё не проверено

- [ ] «Вид → Маскот на рабочем столе»: отдельная поверхность 360×460, рабочий стол виден между панелью, облачком и персонажем; нет чёрного/непрозрачного фона.
- [ ] XP-окно остаётся доступным, пока новая поверхность не получила снимок состояния и не готова рисоваться. При заблокированном JS/ошибке загрузки — возврат не позднее 15 секунд, без пустого единственного окна.
- [ ] Перетаскивание за имя/точки, кнопки/поле ввода не являются drag-областями. Фокус ввода и Enter работают.
- [ ] Переключение во время запроса и во время TTS не сбрасывает диалог, не повторяет API-запрос и не удваивает голос.
- [ ] Отправка из поверхности, mute, уход, выглядывание, «Позвать обратно» и автоматический возврат работают при скрытом XP-окне.
- [ ] Выбрать Clippy/Rover/Merlin в поверхности: текущий запрос/звук отменяются, при включённой памяти восстанавливается свой диалог; выбор текущего не очищает его. Courtney/Earl недоступны.
- [ ] Выбор персонажа мышью и клавиатурой работает при click-through; открытый список не отдаёт клики окну позади. При фокусе на списке более 10 секунд режим безопасно отключается.
- [ ] «Стоп голос» прерывает воспроизведение; «Стоп TTS» отменяет подготовку/очередь. Следующая реплика озвучивается, если динамик остался включён.
- [ ] «Стоп» при запросе работает в поверхности, мини- и полном XP; можно отправить новый текст, поздний старый ответ не появляется. Отправленное сообщение остаётся в истории. Проверять сначала в демо/с подставным API, без обязательных расходов.
- [ ] XP-кнопка, Esc, клик/пункт трея, повторный запуск возвращают тот же диалог.
- [ ] Alt+F4 в поверхности возвращает XP, не завершает приложение. Alt+F4 в XP завершает всё.
- [ ] Падение renderer поверхности возвращает XP; таймаут и поздняя загрузка не создают призрачных окон.
- [ ] Быстро включить/вернуть/включить режим: ровно одна поверхность. Выход из трея не воскрешает XP-окно.
- [ ] Pin применяется к обоим окнам. Поверхность не разворачивается и не меняет размер вручную.
- [ ] 100/125/150/200% DPI, разные масштабы двух мониторов, отрицательные координаты, отключение монитора: панели доступны, поверхность не теряется.
- [ ] Позиция поверхности запоминается отдельно; после перезапуска открывается XP, а не скрытый/прозрачный режим.
- [ ] Click-through выключен по умолчанию. Явно включить кнопкой мыши: клики через пустые промежутки доходят до тестового окна позади, кнопки/облачко/маскот/ввод сохраняют захват. Это прямоугольные области с запасом, не пиксельный контур.
- [ ] Вернуть указатель с пустого участка на XP-кнопку: захват возвращается. Проверить быстрые перемещения и немедленные клики: записать задержки/пропущенные клики (опрос 50 мс, карта 250 мс).
- [ ] Ввод текста, выделение, drag за заголовок, уход/возврат/смена реплики и появление ошибки не делают управление недоступным.
- [ ] Приостановить renderer более чем на 1,25 секунды: основное окно поверхности снова принимает клики, режим отключён. Продолжить renderer: не включается сам.
- [ ] Сворачивание/скрытие/reload/долгое зажатие указателя или фокус на списке персонажей дольше 10 секунд отключают click-through. Повторное открытие поверхности также начинается с выключенного режима.
- [ ] Проверить масштаб 100/125/150/200%, переход между разными DPI, отключение монитора: области захвата совпадают с панелями; при сомнениях режим отключается вручную.
- [ ] Во время теста держать доступным трей/повторный запуск для возврата. Не задавать `ignoreMouseEvents` вручную. В Linux переключатель должен быть недоступен; macOS требует отдельного ручного прогона.

## Маскот и звук

- [ ] Clippy/Rover/Merlin: ожидание, размышление, реплика, обида и возврат не оставляют пустой спрайт.
- [ ] Быстро сменить действие несколько раз: завершается текущая цепочка выхода, запускается последнее действие.
- [ ] Обидеть → свернуть → подождать больше паузы → вернуть: просроченный фоновый таймер не уводит маскота снова.
- [ ] Системные русские голоса перечисляются; три отдельных настройки, скорость, озвучка по кнопке работают.
- [ ] Во время длинной реплики остановить звук/сменить маскота/закрыть окно: аудио прекращается.
- [ ] Если системный голос выдаёт `word` boundaries, подсветка следует словам в облачке обоих режимов; после stop/смены персонажа не возвращается от старого события. Если boundaries нет или выбран OpenAI TTS без таймингов, нет выдуманной подсветки.
- [ ] Новый SVG-жест имеет оформление текущего персонажа; не выдаётся за оригинальную Microsoft анимацию.
- [ ] Системный голос отсутствует: понятное уведомление, чат продолжает работать.
- [ ] Опциональный OpenAI TTS: только с отдельным ключом и согласием на расходы; проверить русское произношение и воспроизведение Blob-аудио в Electron.
- [ ] Тихие часы (через полночь тоже): нет звука и самостоятельных реплик; текстовый чат доступен.
- [ ] «Без подколов»: мягкий режим, грубого жеста нет; индивидуальный запрет жеста сильнее ответа LLM.
- [ ] Память сессии включена: при возврате к персонажу свой разговор. Отключена: чужие сохранённые разговоры удаляются.

## Безопасность и выход

- [ ] Ссылки открываются во внешнем браузере; удалённая страница не заменяет renderer.
- [ ] Никаких ключей/текстов в `window-state.json` и логах.
- [ ] После перезапуска ключи, история и кэш аудио отсутствуют.
- [ ] Нет запросов OpenAI TTS до выбора провайдера + задания отдельного ключа + включения динамика.

Для результатов записать ОС/сборку, DPI/мониторы, версию Electron, шаги воспроизведения, ожидаемое и фактическое поведение. Не включать API-ключи в скриншоты и отчёты.
