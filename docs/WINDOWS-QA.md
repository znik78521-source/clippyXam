# Windows QA: NT/minimal 0.2.0 — ещё не выполнено

Unit/mock и браузерные тесты не подтверждают реальную Windows, GPU, микрофон или голоса. Проверять исходники без build/exe: Windows 10/11, Node 22.12+, START-WINDOWS.cmd. Нужен свой ключ OpenRouter, маршрут openrouter/free. Платные TTS для проверки не требуются.

## Подключение и UI

- [ ] При keyless запуске сразу окно подключения; ссылка открывается во внешнем браузере. Ключ не видно в поле и не сохраняется после выхода.
- [ ] Серая NT-рамка, минимальный UI: персонаж/реплика/поле/микрофон/шестерёнка. Демо нет.
- [ ] 360×460 и минимум 320×400: доступен ввод, настройки прокручиваются, нет горизонтальной прокрутки.
- [ ] Перетаскивание за заголовок, resize, minimize/maximize/restore. Кнопки не являются drag-областью.
- [ ] DPI 100/125/150/200%, два монитора, отрицательные координаты, отключение монитора, перезапуск с сохранённой геометрией.
- [ ] Трей: always-on-top, возврат, скрытие, выход. Повторный START возвращает существующее окно.
- [ ] Enter отправляет один запрос; отмена и смена персонажа игнорируют запоздалый ответ.
- [ ] 401 возвращает подключение; 429 показывает лимит без paid fallback. ID платной модели не принимается.

## Виджет

- [ ] Настройки → Виджет: реальный прозрачный фон, без чёрного прямоугольника.
- [ ] Основное окно скрывается только после готовности поверхности; ошибка/таймаут/падение поверхности возвращают владельца.
- [ ] Сообщения/уход/таймеры/голос продолжают работать, без двойных запросов и двойной озвучки.
- [ ] Настройки из виджета → отмена возвращает виджет, применение сохраняет выбранный checkbox. Смена персонажа/удаление ключа работают.
- [ ] Удаление ключа и 401 не оставляют пустой скрытый диалог подключения; попытка открыть виджет через трей без ключа возвращает подключение.
- [ ] Кнопки caption: свернуть, вернуть обычное окно, закрыть приложение. Esc/трей/повторный запуск возвращают владельца; Alt+F4 поверхности возвращает, не завершает приложение.
- [ ] Пропуск кликов штатно выключен: не ожидать pixel-perfect click-through. Проверить, не мешает ли прямоугольная область рабочего стола.

## Микрофон и TTS

- [ ] Windows PowerShell/System.Speech видит совместимый ru-RU recognizer. Языковой пакет/Win+H не доказывают это. Отметить отсутствие как ограничение, не как успешное распознавание.
- [ ] Нажатие микрофона: распознаёт русский текст default-микрофоном, вставляет только черновик. Enter отправляет отдельно.
- [ ] Повторное нажатие/настройки/смена персонажа/закрытие отменяют ввод, поздний результат не меняет черновик.
- [ ] Нет микрофона, нет recognizer, запрет доступа, тишина, повторный запуск ввода: понятная ошибка/завершение, без зависшего PowerShell. Watchdog 22 секунды.
- [ ] Системная озвучка: голос есть, правильный тембр, остановка кнопкой, смена персонажа не озвучивает старый ответ.
- [ ] Тихие часы и выключение озвучки отменяют очередь. Ошибка системного голоса не включает платный OpenAI автоматически.
- [ ] Выход останавливает озвучку, распознавание, Electron и dev-сервер.

## Поведение и данные

- [ ] Память сессии включается явно, разговоры персонажей разделены и исчезают после перезапуска.
- [ ] Отчёт без ключей/переписки: версия Windows, DPI, действие, ожидаемый/полученный результат. Шаблон рядом.
